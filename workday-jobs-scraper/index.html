Workday jobs scraper

Paste a company’s Workday careers site (company.wdN.myworkdayjobs.com/SiteName) and get its live job postings in clean rows: title, location, remote or onsite, employment type, posting date, apply URL, and the salary range when it appears in the posting.

For recruiters and job boards that need large employers’ openings, and for teams tracking hiring at enterprises that run on Workday.

Try the Lite version first (no per-result charge) Full version in the Apify Store

What you get

How to use it

In the Apify Store (no code)

  1. Start with the Lite version (up to 25 results per run, no per-result charge), or open the full version, and click Try for free (Apify account, free plan included).
  2. Paste your list in the form, or use the input above.
  3. Click Start and download the results as JSON, CSV or Excel.

From your code (API)

curl -X POST "https://api.apify.com/v2/acts/cleanyield~ats-jobs-scraper/run-sync-get-dataset-items?maxTotalChargeUsd=1" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "companies": [
    "https://salesforce.wd12.myworkdayjobs.com/External_Career_Site",
    "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite"
  ],
  "maxJobsPerCompany": 10,
  "includeDescription": "none"
}'

Create an API token in Apify Console → Settings → Integrations. maxTotalChargeUsd caps what the run can cost; the run stops there.

n8n and Make

In n8n, add the official Apify node; in Make, use the Apify app. Choose the Actor cleanyield/ats-jobs-scraper, paste the input JSON above, and read the dataset items in the next step. You can also schedule the Actor in Apify and send the results to a webhook, Google Sheets or Slack.
