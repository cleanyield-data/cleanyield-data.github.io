How to get job postings from the Greenhouse API

Short answer: Greenhouse publishes every company’s open jobs in a free Job Board API that needs no key: GET https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs?content=true. For one company that is enough; for many companies, salaries as a yearly range and the same format as Lever, Workday and 16 other hiring systems, use Clean Yield’s ATS Jobs Scraper.

Do it yourself with the official source

One company, from the command line. The board token is the last part of job-boards.greenhouse.io/<token>; careers pages that embed Greenhouse show it as boards.greenhouse.io/embed/job_board?for=<token>.

curl "https://boards-api.greenhouse.io/v1/boards/airbnb/jobs?content=true&pay_transparency=true"

What you have to handle yourself

  • One board per request, and you need the exact board token.
  • Pay ranges come only with pay_transparency=true and only when the company enables them, in cents and sometimes repeated per region.
  • Location is free text: there is no remote, hybrid or onsite field.
  • Lever, Ashby, Workday and the rest each have a different format.

When Clean Yield’s Actor saves time

  • Type a company name, website or board URL; the board is found for you.

Questions

Do I need an API key for the Greenhouse Job Board API?

No. Listing jobs is public and needs no authentication. Only submitting applications through the API needs the company’s key.

Does it return closed jobs?

No. The board lists only jobs that are open now, and so does the Actor, which reads it when the run starts.

Can I get all jobs from many Greenhouse companies at once?

Yes. Put the companies in the Actor’s companies list (names, websites or board URLs); each row says which company it belongs to.
