How to get public tenders from Colombia and Chile by API

Short answer: Colombia publishes its tenders as open data on datos.gov.co (SECOP II) and Chile through Mercado Público’s open OCDS API; both are free, but fields, currencies and status names differ. Clean Yield’s Latin America Public Tenders returns both, plus Brazil, Paraguay and Uruguay (beta), in one format with the bid deadline, the amount in USD when the tender states one and a link to the official notice.

Do it yourself with the official source

Colombia (SECOP II processes, Socrata API) and Chile (OCDS list of the month), no registration:

curl -G "https://www.datos.gov.co/resource/p6dx-8zbt.json" \
  --data-urlencode "\$where=estado_del_procedimiento='Publicado' AND fecha_de_publicacion_del >= '2026-11-09T00:00:00'" \
  --data-urlencode "\$limit=50"
curl "https://apis.mercadopublico.cl/OCDS/data/listaA%C3%B1oMes/2026/11/0/100"

What you have to handle yourself

  • SECOP’s status column alone misleads: processes in "Evaluación" or "Aprobado" can still be open until their deadline, and direct contracts are mixed in.
  • Chile’s list returns only codes; each tender needs another request, and the open data can lag the portal by a few hours.
  • Amounts come in COP or CLP, with different field names in each country.

When Clean Yield’s Actor saves time

  • One format for Colombia, Chile, Brazil, Paraguay and Uruguay (beta).
  • "Open" means the bid deadline is still ahead, checked per tender; direct contracts are left out.
  • Amount in USD next to the local amount, English titles and filters by sector, keyword, amount and date.
  • Can run daily and return only new tenders.

Questions

Do I need a Mercado Público API ticket?

Not for this. The ticket is for Mercado Público’s classic API; the OCDS open data used here needs no registration.

How fresh is it?

Each run reads the official sources when it starts. SECOP II open data and Chile’s OCDS can lag their portals by a few hours.
