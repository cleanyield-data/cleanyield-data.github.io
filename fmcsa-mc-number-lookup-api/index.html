How to look up an FMCSA carrier by MC number

Short answer: For one carrier, search the MC number in FMCSA’s SAFER Company Snapshot (search by MC/MX number). For a list, or from code, Clean Yield’s FMCSA Carrier Lookup takes MC numbers and returns the USDOT number, legal name, authority status per docket, insurance on file and fleet size from FMCSA’s official data, re-checking statuses live on SAFER when the open data may be out of date.

Do it yourself with the official source

One carrier, no key needed (the same page you see in a browser):

https://safer.fmcsa.dot.gov/query.asp?searchtype=ANY&query_type=queryCarrierSnapshot&query_param=MC_MX&query_string=135797

What you have to handle yourself

  • One carrier per page, in HTML: fine to check a carrier, slow for a list.
  • FMCSA’s open data (data.transportation.gov) is free, but the Company Census holds only three dockets per carrier: J.B. Hunt’s MC-135797 is not in its census row (checked 2026-11-11), so you also need the Motus authority dataset.
  • Insurance, authority, census and inspections are separate datasets you have to join yourself.

When Clean Yield’s Actor saves time

  • Paste MC, FF or MX numbers in any format (MC-135797, mc 135797, 135797).
  • Census, Motus authority, insurance filings, out-of-service orders and inspections joined into one row.

Questions

Can I search by MC number with the FMCSA API?

FMCSA’s QCMobile API has a docket-number search but needs a free web key. The open data needs no key but spreads the MC number across several datasets.

Does it return insurance?

Yes, the policies FMCSA has on file (insurer, coverage, effective date). If none is on file, the field is empty.
