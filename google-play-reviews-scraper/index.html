Google Play reviews scraper

Paste a Google Play link and get the app’s reviews with star rating, text, date, app version and the developer’s reply when there is one, filtered by language, rating or date. Export as JSON, CSV or Excel, or add the App Store version of the same app.

For Android product teams, customer support leads checking reply coverage, and researchers comparing apps.

How to use it

In the Apify Store (no code)

  1. Start with the free Lite version (up to 25 results per run, no per-result fee), or open the full version, and click Try for free (Apify account, free plan included).
  2. Paste your list in the form, or use the input above.
  3. Click Start and download the results as JSON, CSV or Excel.

From your code (API)

curl -X POST "https://api.apify.com/v2/acts/cleanyield~app-store-google-play-reviews/run-sync-get-dataset-items?maxTotalChargeUsd=1" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "apps": [
    "https://play.google.com/store/apps/details?id=com.spotify.music"
  ],
  "languages": [
    "en"
  ],
  "maxReviewsPerApp": 50
}'

Create an API token in Apify Console → Settings → Integrations. maxTotalChargeUsd caps what the run can cost; the run stops there.

n8n and Make

In n8n, add the official Apify node; in Make, use the Apify app. Choose the Actor cleanyield/app-store-google-play-reviews, paste the input JSON above, and read the dataset items in the next step. You can also schedule the Actor in Apify and send the results to a webhook, Google Sheets or Slack.
