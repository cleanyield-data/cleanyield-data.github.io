FMCSA carrier lookup API

Look up US trucking companies by USDOT or MC number, in bulk, or list the carriers of a state, city, ZIP code or radius, including the ones that just registered. Each row comes from official FMCSA data: authority, insurance on file, safety record, fleet size, contact and a lead score.

For freight brokers vetting carriers, truck insurance agents and factoring companies looking for new authorities, and developers who need FMCSA data as JSON.

How to use it

In the Apify Store (no code)

  1. Start with the Lite version (up to 25 results per run, no per-result charge), or open the full version, and click Try for free (Apify account, free plan included).
  2. Paste your list in the form, or use the input above.
  3. Click Start and download the results as JSON, CSV or Excel.

From your code (API)

curl -X POST "https://api.apify.com/v2/acts/cleanyield~fmcsa-carrier-data/run-sync-get-dataset-items?maxTotalChargeUsd=1" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "dotNumbers": [
    "80806",
    "53467",
    "264184"
  ]
}'

Create an API token in Apify Console → Settings → Integrations. maxTotalChargeUsd caps what the run can cost; the run stops there.

n8n and Make

In n8n, add the official Apify node; in Make, use the Apify app. Choose the Actor cleanyield/fmcsa-carrier-data, paste the input JSON above, and read the dataset items in the next step. You can also schedule the Actor in Apify and send the results to a webhook, Google Sheets or Slack.
