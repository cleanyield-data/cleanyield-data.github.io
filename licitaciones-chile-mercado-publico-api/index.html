¿Cómo obtener las licitaciones de Mercado Público (Chile) por API sin ticket?

Respuesta corta: La API clásica de Mercado Público pide un ticket, pero ChileCompra también publica las licitaciones en su API OCDS abierta (apis.mercadopublico.cl/OCDS), sin registro. La Licitaciones Públicas de Latinoamérica de Clean Yield la lee por ti y devuelve cada licitación con comprador y RUT, región, fecha de cierre y monto en pesos y en dólares cuando se informa.

Hazlo tú con la fuente oficial

Lista de licitaciones del mes (códigos) y después el detalle de cada una:

curl "https://apis.mercadopublico.cl/OCDS/data/listaA%C3%B1oMes/2026/11/0/100"
curl "https://apis.mercadopublico.cl/OCDS/data/tender/2318-86-LE26"

Lo que tienes que resolver por tu cuenta

  • La lista solo trae códigos: cada licitación es una consulta más (el 11/11 había más de 3.300 en el mes).
  • Los datos abiertos pueden ir unas horas atrás del portal.
  • Formato OCDS: el monto, las fechas y el comprador están en partes distintas del documento.

Cuándo te ahorra tiempo el Actor de Clean Yield

  • Sin ticket ni registro: eliges Chile y corres.
  • Una fila por licitación con comprador, RUT, región, cierre y monto en CLP y USD.
  • El mismo formato que Colombia, Brasil, Paraguay y Uruguay (beta), con filtros por rubro, monto y fecha.
  • Se puede programar todos los días y recibir solo las nuevas.

Desde tu código (API)

curl -X POST "https://api.apify.com/v2/acts/cleanyield~latam-public-tenders/run-sync-get-dataset-items?maxTotalChargeUsd=1" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "countries": [
    "CL"
  ],
  "status": [
    "open"
  ],
  "publishedWithinDays": 3,
  "maxResults": 10
}'

Crea un token en Apify Console → Settings → Integrations. maxTotalChargeUsd pone un tope a lo que puede costar la corrida; se corta ahí.

Preguntas

¿Para qué sirve entonces el ticket?

Para la API clásica de Mercado Público (api.mercadopublico.cl/servicios). Para leer licitaciones publicadas alcanza con los datos abiertos OCDS.

¿Por qué algunas no traen monto?

Porque el organismo no publicó un monto estimado. En ese caso amount queda vacío; no se inventa.
