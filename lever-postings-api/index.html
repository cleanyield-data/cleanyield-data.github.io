How to get job postings from the Lever API

Short answer: Lever’s public Postings API returns a company’s published jobs with no key: GET https://api.lever.co/v0/postings/{company}?mode=json (EU-hosted boards use api.eu.lever.co). Clean Yield’s ATS Jobs Scraper reads the same feed for many companies at once, at the 1 request per second Lever asks for, and returns the salary when stated in the same format as Greenhouse and Workday.

Do it yourself with the official source

The company slug is the part after jobs.lever.co/.

curl "https://api.lever.co/v0/postings/spotify?mode=json"

What you have to handle yourself

  • One company per request, and the slug must be exact (EU boards answer on a different host).
  • Salary appears only when the company fills Lever’s salary range; ranges in the description are not parsed.
  • Dates are Unix milliseconds and the format differs from every other ATS.

When Clean Yield’s Actor saves time

  • Type a company name or URL; US and EU Lever hosts are tried for you.
  • Salary from Lever’s field or from an explicit range in the text, as yearly min and max.
  • Filters by keyword, location, remote and date, and monitor mode for new jobs only.
  • The same columns across Lever, Greenhouse, Ashby, Workday and 15 more systems.

Questions

Do I need an API key for Lever postings?

No. Published postings are public; Lever’s documentation says they may be read by third parties. Keys are only for a company’s own Lever account data.

Does it support jobs.eu.lever.co?

Yes. Paste the EU URL; for a bare company name the EU host is tried automatically.
