Find company emails from a website

Paste a list of websites and get the contact emails each company publishes (info@, sales@, press@), the page where every email was found, phone numbers in E.164 when listed, and social profiles. Personal emails are left out by default.

For founders and SDRs doing outreach, agencies cleaning lead lists and anyone who needs the public contact of many companies without opening each site.

How to use it

In the Apify Store (no code)

  1. Start with the free Lite version (up to 25 results per run, no per-result fee), or open the full version, and click Try for free (Apify account, free plan included).
  2. Paste your list in the form, or use the input above.
  3. Click Start and download the results as JSON, CSV or Excel.

From your code (API)

curl -X POST "https://api.apify.com/v2/acts/cleanyield~company-enrichment-from-website/run-sync-get-dataset-items?maxTotalChargeUsd=1" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "katzsdelicatessen.com",
    "tartinebakery.com",
    "russanddaughters.com",
    "cafetortoni.com.ar"
  ],
  "sections": [
    "contacts",
    "social"
  ]
}'

Create an API token in Apify Console → Settings → Integrations. maxTotalChargeUsd caps what the run can cost; the run stops there.

n8n and Make

In n8n, add the official Apify node; in Make, use the Apify app. Choose the Actor cleanyield/company-enrichment-from-website, paste the input JSON above, and read the dataset items in the next step. You can also schedule the Actor in Apify and send the results to a webhook, Google Sheets or Slack.
