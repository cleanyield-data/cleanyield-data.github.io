How to get job postings from Workday

Short answer: Workday has no documented public jobs API, but every myworkdayjobs.com careers site loads its list from a public JSON endpoint: POST https://{tenant}.wdN.myworkdayjobs.com/wday/cxs/{tenant}/{site}/jobs, 20 jobs per page. To skip the paging, the relative dates and one extra request per job, paste the careers site URL into Clean Yield’s ATS Jobs Scraper and get clean rows with exact posting dates.

Do it yourself with the official source

The tenant, the wdN host and the site name are all in the careers site URL (here nvidia, wd5 and NVIDIAExternalCareerSite).

curl -X POST "https://nvidia.wd5.myworkdayjobs.com/wday/cxs/nvidia/NVIDIAExternalCareerSite/jobs" \
  -H "Content-Type: application/json" \
  -d '{"appliedFacets":{},"limit":20,"offset":0,"searchText":""}'

What you have to handle yourself

  • At most 20 jobs per request, so large employers need many pages.
  • The list gives "Posted Today" or "Posted 30+ Days Ago", not a date; the date and description need one more request per job.
  • Undocumented: Workday can change it, and some tenants ask robots in robots.txt to stay out.

Questions

Is there an official Workday jobs API?

Workday’s official APIs are for the company’s own HR data and need its credentials. Public careers sites have no documented API; their pages use the JSON endpoint above.

Does a company name work, or do I need the URL?

For Workday the Actor needs the careers site URL or the company website (for example nvidia.com); a bare name is not enough.

Why is salary empty?

Workday has no salary field. The Actor fills it only when the posting text states a range, which is common for US roles and rare elsewhere.
